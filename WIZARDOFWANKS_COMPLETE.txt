### Database Schema

#### users table
- id (UUID, PRIMARY KEY)
- email (VARCHAR, UNIQUE)
- password (VARCHAR, hashed)
- name (VARCHAR)
- role (VARCHAR, admin/user)
- is_active (BOOLEAN)
- created_at (TIMESTAMP)
- updated_at (TIMESTAMP)
- last_login (TIMESTAMP)

#### templates table
- id (UUID, PRIMARY KEY)
- name (VARCHAR)
- category (VARCHAR)
- description (TEXT)
- content (TEXT)
- created_by (UUID, FOREIGN KEY)
- is_deleted (BOOLEAN)
- created_at (TIMESTAMP)
- updated_at (TIMESTAMP)
- view_count (INTEGER)

#### audit_logs table
- id (UUID, PRIMARY KEY)
- user_id (UUID, FOREIGN KEY)
- action (VARCHAR)
- resource_type (VARCHAR)
- resource_id (UUID)
- details (JSONB)
- created_at (TIMESTAMP)
