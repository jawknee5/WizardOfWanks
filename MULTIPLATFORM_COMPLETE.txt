🚀 QUICK START BY PLATFORM

WINDOWS/MAC/LINUX (Web):
  npm install
  npm start
  → http://localhost:3000

iOS (Native):
  cd mobile
  npm install
  eas build --platform ios
  → Submit to App Store

Android (Native):
  cd mobile
  npm install
  eas build --platform android
  → Submit to Play Store

macOS (Docker - Apple Silicon):
  docker-compose -f docker-compose.multiarch.yml up -d
  → http://localhost:3000

📱 INSTALLATION FOR END USERS

iOS Users:
  1. Open App Store
  2. Search "WizardOfWanks"
  3. Tap Install
  4. Open app

Android Users:
  1. Open Play Store
  2. Search "WizardOfWanks"
  3. Tap Install
  4. Open app

Web Users:
  1. Visit https://your-domain.com/wizardofwanks
  2. Tap Menu → "Add to Home Screen"
  3. Tap app icon

macOS Users:
  1. Run: docker-compose -f docker-compose.multiarch.yml up
  2. Open: http://localhost:3000
