USAGE FLOW
================================================================================

1. INSTALL (1-Click)
   User downloads Receipt-Processor-Setup.exe (or .dmg/.AppImage)
   Click Next, Next, Done
   App launches automatically

2. SCAN RECEIPT
   Click "📸 Capture Photo"
   Take photo of receipt
   OCR extracts all 20+ fields automatically

3. EDIT ON-THE-FLY
   Edit any field in real-time
   Modify line items individually
   Update totals dynamically
   All changes tracked in edit history

4. SAVE TO QUEUE
   Click "Save to Queue"
   Transaction stored locally
   Audit entry created with timestamp

5. REVIEW & APPROVE (Offline OK)
   Go to "Transaction Queue" tab
   Select transactions to approve
   User explicitly approves for sync
   System records approval with user ID

6. SYNC WHEN ONLINE
   When internet connection detected
   Approved transactions prepared
   User clicks "Sync Now" (manual)
   Transactions sent to backend

7. BACKEND PROCESSES
   Backend receives transactions
   Processes inventory updates
   Creates accounting entries
   Returns success/failure

8. LOCAL UPDATE
   App marks transaction as synced
   Audit trail records completion
   Local state updated
   User can view sync status

9. AUDIT & COMPLIANCE
   Go to "Audit Trail" tab
   View all operations with timestamps
   Export as JSON or CSV
   Print compliance report

API REQUIREMENTS (Your Backend)
================================================================================

Your backend must provide these endpoints:

POST /api/transactions/sync
  Request: { transactions: [...approved txs...] }
  Response: { synced: [...], failed: [...] }

POST /api/inventory/update
  Request: { items: [...] }
  Response: { updated: number }

POST /api/audit/log
  Request: { logs: [...] }
  Response: { logged: number }

Example Transaction Format:
{
  id: "uuid",
  receiptData: {
    storeName: "Store Name",
    total: 45.99,
    items: [
      { upcCode: "123456789012", description: "Item", qty: 2, unitPrice: 22.99 }
    ],
    tax: 3.99,
    paymentMethod: "card",
    authCode: "ABC123",
    transactionRef: "TRX001",
    operatorCode: "OP01",
    date: "2024-05-28",
    time: "14:30"
  },
  metadata: {
    queuedAt: "2024-05-28T14:30:00Z",
    syncApprovedAt: "2024-05-28T14:35:00Z",
    syncApprovedBy: "john_smith"
  }
}
