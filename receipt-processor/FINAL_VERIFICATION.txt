   User downloads installer
   → Runs 1-click setup
   → App launches

   User clicks "📸 Scan"
   → Takes receipt photo
   → OCR processes (2-5 sec)
   → Shows extracted data

3. EDIT (1-5 minutes)
   User reviews fields
   → Makes any edits
   → Changes tracked
   → All fields editable

4. SAVE (1 second)
   User clicks "Save"
   → Transaction queued
   → Stored locally
   → Audit entry created

5. APPROVE (1-2 minutes)
   User goes to Queue
   → Selects transactions
   → Clicks "Approve"
   → Ready for sync

   User clicks "Sync Now"
   → Transactions sent
   → Backend processes
   → Status updates
   → Audit recorded

7. VERIFY (30 seconds)
   User checks Audit Trail
   → Views all operations
   → Export compliance report
   → Complete transparency
